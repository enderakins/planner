# Планировщик

Личный календарь заданий: предметы, дедлайны, описание, статус. Статический сайт (index.html, style.css, app.js, config.js) без сборки. Данные хранятся в бесплатной базе Supabase и синхронизируются между телефоном и ноутбуком. Вход по почте и паролю, данные видны только вам.

## 1. База данных (Supabase, бесплатно)

1. Зарегистрируйтесь на supabase.com, нажмите New project (регион выберите ближайший, например Frankfurt), задайте пароль базы.
2. Откройте SQL Editor, вставьте содержимое файла `supabase.sql`, нажмите Run.
3. Authentication, Users, Add user, Create new user: введите свою почту и пароль, отметьте Auto Confirm User.
4. Authentication, Sign In / Providers (или Settings): отключите Allow new users to sign up, чтобы никто, кроме вас, не мог создать аккаунт.
5. Project Settings, API: скопируйте Project URL и ключ anon public в файл `config.js`.

Ключ anon публичный по своей природе. Защищают данные вход и правило из `supabase.sql`: пользователь видит только свою строку.

## 2. Публикация на GitHub Pages

1. На github.com создайте публичный репозиторий.
2. Add file, Upload files: загрузите index.html, style.css, app.js, config.js (уже с вашими значениями), README.md, supabase.sql.
3. Settings, Pages: Deploy from a branch, ветка main, папка root, Save.
4. Сайт откроется по адресу https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/. Войдите на каждом устройстве один раз, сессия сохранится.

## Как работает синхронизация

Каждое изменение сохраняется на устройстве сразу и отправляется в базу через долю секунды. Когда вы возвращаетесь на вкладку или в приложение, сайт подтягивает свежие данные. Если связи нет, изменения остаются на устройстве и уходят позже; статус виден в верхней панели. Работа идёт по принципу «последнее сохранение побеждает»: не редактируйте одновременно на двух устройствах.

Бесплатный проект Supabase ставится на паузу после недели без активности. Если сайт давно не открывали, зайдите в панель Supabase и нажмите Restore project.

Резервная копия в файл (страница «Предметы») остаётся как запасной вариант.
